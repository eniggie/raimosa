## Description (≤ 10,000 chars)
```
RAIMOSA AI is a local desktop commander. One assistant — OVIA AI — plans work,
asks for your approval, carries it out through named tools, and writes a
tamper-evident receipt for everything it does. It runs entirely on your
machine. There is no cloud account, no telemetry, and no external model.

WHY RAIMOSA IS DIFFERENT

Most assistants ask you to trust them. RAIMOSA proves itself instead. Every
tool it runs is recorded in an append-only, hash-chained ledger you can read
and export at any time. Alter, delete, or reorder a single receipt and the
chain breaks — and the app tells you. What RAIMOSA did is never a matter of
belief; it is evidence you hold.

WHAT IT CAN DO

• Find, summarize, and preview files inside folders you approve
• Analyze storage and surface exact duplicate files
• Organize files with an exact plan you approve first — never a surprise move,
  and nothing is ever deleted
• Create documents, spreadsheets, and presentations
• Check device vitals: CPU, memory, disk, battery, uptime
• Inspect processes, compare folders, monitor changes
• Read and write the clipboard, capture the screen, send notifications
• Open documents and launch or quit applications
• Sleep, restart, or shut down — with a typed confirmation for the big ones
• Pair a phone as a revocable local-network remote

HOW IT KEEPS YOU IN CONTROL

• The engine answers requests from this computer only.
• "All Access" is a short, visible, expiring session. It never survives a
  restart — if the app stops, that authority is revoked and recorded.
• Emergency Stop is a real switch: while it is on, every tool is blocked, and
  it stays blocked across restarts until you clear it.
• Anything sensitive requires your explicit approval. File moves need an exact
  plan plus a one-time confirmation. Writes never overwrite.
• File contents are never written to the ledger — only paths, sizes, and
  cryptographic hashes.

RAIMOSA is for people who want a capable assistant on their computer without
handing over blind trust. It does real work, and it hands you the receipts.

© ECONTEUR LLC
```
